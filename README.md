# 个人简介  
这里是Nanagokyuu，一个普通的计算机科学专业的大学生  
## 兴趣  
🙌 DIY：挺喜欢折腾组装机的，经常搭配出一些头重脚轻吕布骑狗的配置，实用性不重要，好玩才是最关键的，毕竟最优解千篇一律，但不均衡的才是百花齐放对吧  

🎵 音乐：喜欢 Drum'n'Bass，主要是是 Liquid Funk、Neurofunk 之类的，当然其他的也不排斥，还是相当杂食的，不是很经常听，也不是很喜欢流媒体的订阅制，一般都是自己买实体专或数字专，尤其是 CD 拿在手上的感觉确实是数字版比不了的  

🕹️ 游戏：是个打音游的，移动端主要玩 Arcaea，PTT 13.200+，其他音游也有涉猎，算是什么都玩点，街机主要玩 CHUNITHM 和 maimai。另外我经常发手元，在 Bilibili 上：[个人主页](https://space.bilibili.com/488196059?spm_id_from=333.1007.0.0) ，至于其他的游戏的话，玩的其实也不算多，2077、地平线6、丝之歌之类的还是我比较喜欢的类型，对于二游的话就没什么耐心了，我也不太喜欢以内购抽卡为核心的游戏，就像我不喜欢流媒体音乐一样    

📱 软件开发：偶尔会搞搞一些 iOS/macOS 上的软件开发，目前做的软件都会开源的，暂时不打算商业化：[App Store 页面](https://apps.apple.com/cn/app/%E6%89%AB%E9%9B%B726/id6757836780)、[GitHub 页面](https://github.com/Nanagokyuu/Minesweeper)
